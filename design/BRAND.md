# NoteIt brand and logo usage

## Name

The name is **NoteIt**: one word, capital N, capital I, no space. Never "Noteit", "Note It" or "NOTEIT". Use `noteit` in identifiers and file names.

## Writing

UI labels, menu items and buttons use Title Case. Keep copy short and plain.

## Logo

The NoteIt app icon is a white squiggle and pencil on a violet → indigo gradient (`#6E5BFF`, `#3A3FD9`, `#1E2470`). It is drawn by `scripts/make_icon.swift` and pre-rendered into `Resources/AppIcon.iconset`. The menu bar glyph uses the same squiggle + pencil mark.

`design/assets/` also keeps alternative artwork:

- `assets/logo/`: the Swift Page mark (a note page on speed streaks), in colour, white and a small version for 32 px and below
- `assets/app-icon/`: Swift Page app icon SVGs (light, dark, tinted, small) and an `AppIcon.iconset/`; `alt-paper/` holds an earlier paper sheet + yellow pencil icon
- `assets/menu-bar/`: menu bar template images (idle and capturing)
- `assets/icons/`: a line icon set for the website and docs

## Using the logo

- Don't alter, recolour, rotate or distort the logo, or add effects to it.
- Don't use the name or logo in a way that suggests the NoteIt project endorses you or your product.
- You can use the logo to link to or write about NoteIt.
- Forks and modified versions must use their own name and icon, so users can tell them apart from the official app.
