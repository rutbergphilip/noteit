# NoteIt Linking Implementation Plan

**Goal:** Add links between notes with `[[` suggestions, backlinks, unlinked mentions and links that survive renames, plus heading links, daily notes, templates with variables and an outline panel. It must work offline, with sync, and stay fast at 10,000 notes.

**Architecture:**
- A note link is an ordinary `.link` attribute whose URL is `noteit://note/<UUID>[?heading=]` or `noteit://note?title=` (unresolved). RTFD, sync, history, copy/paste and `noteit-doc` already carry `.link`, so there is no storage format change. Foundations already lets the Swift `DocValidation` and the TypeScript validator accept `noteit:` links (program §2 step 2); this plan doesn't touch either.
- `NoteLink` (the URL grammar) lives in `NoteItCore`, so `automation`'s `URLCommand` parser, the phone and the Mac app share it. This plan owns its shape; foundations Task 5.3 builds `NoteLink`, `LinkQuery` and `URLCommand`'s `.note`/`.noteTitle` in wave 0, and this plan doesn't create them. `automation` owns all `noteit://` routing; its `.note`/`.noteTitle` handlers call `NoteStore.followLink(_:from:)` from this plan.
- A new folder `Sources/NoteIt/Linking/` holds the other pure, testable parts:
  - `LinkExtractor`, `OutlineExtractor`, `MentionFinder` (read attributed text);
  - `LinkIndex` (in-memory maps + `link-index.json`), registered as a `DerivedIndex`;
  - `LinkSuggester` (ranking for the `[[` list);
  - `TemplateExpander`, `NavigationHistory`.
- `NoteStore` extensions (`NoteStore+Links`, `NoteStore+Templates`, `NoteStore+DailyUI`) are the only API the UI and other sub-projects use. The link index is kept in step with bodies only through the `DerivedIndex` registry (program §7; shape owned by `organise`, built by foundations Task 4.4); this plan adds no hooks to `NoteStore.swift`. Every change to a note other than typing goes through `NoteStore.editBody` (program §6); rename updates and **Link All** pass `versioning: .recordCurrent`, so `editBody` records one version per changed note (linking never records versions itself), and offer Undo, which restores through `restoreVersion` (itself built on `editBody`).
- Daily notes: `NoteStore+Daily` (`dailyNote(for:createIfMissing:)`), `DailyLogAppender`, and the `DailyNoteTitle`/`DayKey`/`DailyLogLine` code in `NoteItCore` are not built here. Moved to foundations (docs/plans/2026-10-19-foundations.md, Task 4.6), together with the `DailyNotes.isAvailable` gate, which is false until this plan's T14 sets it to true. This plan owns how daily notes behave and look: opening, the calendar, the Today row, the daily template (applied inside `dailyNote(for:createIfMissing:)`), the menu, hotkey and Shortcuts action.
- The editor gets `LinkStyler` (temporary attributes, like `CodeStyler`), the shared `InlineCompletionController` (created here, child panel, reused by `organise` for tags and the query language) with a `LinkCompletionSource`, the `]]` Markdown shortcut and link click routing. Linking owns the main window's inspector: a SwiftUI `.inspector` hosting the Links and Outline tabs, with room for plugin tabs.
- Local API routes for links, outline and templates are registered by this plan through `LocalAPIRouteRegistry` with `linking.<name>` route ids. The daily routes are `automation`'s.

**Tech Stack:** Swift 6.3 toolchain in Swift 5 language mode, SwiftPM, AppKit (TextKit 1 `NSTextView`, as today), SwiftUI (`.inspector`, macOS 14), Foundation. No third-party dependencies. Tests use XCTest via `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`. App builds use plain `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build`.

**Spec:** `docs/specs/2026-10-19-linking-design.md`. The program contract, `docs/specs/2026-10-19-program-design.md`, wins where they disagree.

## Conventions for every task

- Test command (from the repository root): `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --filter <Suite> 2>&1 | tail -20`. Expected: `Executed N tests, with 0 failures`.
- App build: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build 2>&1 | tail -3` and `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build -c release 2>&1 | tail -3` must both end with `Build complete!` and 0 errors.
- Never touch real user data in `~/Library/Application Support/NoteIt`. When running the app, set `NOTEIT_DATA_DIR="$PWD/.selftest/<name>"` (run from the repository root; `<name>` is any folder name) (gitignored). Store tests build a `NoteStore(location: LibraryLocation(url:seedsFreshLibrary: false))` in a temporary folder, as `RecentlyDeletedTests` does.
- Editor behaviour that needs a real window is covered by new steps in `EditorSelfTest` (run with `NOTEIT_EDITOR_SELFTEST=1`), which drives `insertText` and `doCommand(by:)`.
- All state changes go through `NoteStore`. No view writes RTFD files or `library.json`. Code outside the editor changes note text only through `NoteStore.editBody`.
- Every new command gets a palette entry in `PaletteCommandRegistry`; menu shortcuts live in `App/MenuShortcuts.swift`. Each menu command is a `MenuShortcutCommand` case (`newNoteFromTemplate`, `openToday`, `dailyNoteForDate`, `linkToNote`, `goBack`, `goForward`, `toggleInspector`) with the defaults in program §9 (⌥⌘N, ⌃⌘T, none, ⇧⌘K, ⌃⌘←, ⌃⌘→, ⌥⌘I). The task that adds a case deletes its row from foundations' `PlannedMenuShortcuts` and updates `MenuShortcutRules` and `docs/keyboard-shortcuts.md`; `MenuShortcutDefaultsTests` (foundations Task 6.1) must stay green.
- The global hotkey `HotkeyAction.openToday` takes position 7 in foundations' `HotkeyOrder` (program §9: after `captureSelection`, before `showTasks`), whatever order the plans merge in. It is unbound by default, and the same task updates the `ShortcutsSettingsView` tile switch and the `AppDelegate` handler switch.
- Settings go into the existing Editor tab (`Settings/EditorSettingsView.swift`), keys into `PrefKey`/`PrefDefault` in `Settings/Preferences.swift`.
- Commit after each task with Conventional Commits, e.g. `feat(linking): add note link URL grammar`. Never amend, rebase or force.
- No `#Preview`. Comments only where something is non-obvious.

// NoteItCore/NoteLink.swift (public: used by automation's URLCommand, mobile and the Mac app).
// Shape owned here; built by foundations Task 5.3, so this plan doesn't create the file.
public enum NoteLink: Equatable, Hashable, Sendable {
    case note(id: UUID, heading: String?)
    case unresolved(title: String, heading: String?)

    public static let maxTextLength = 120  // longer titles and headings are rejected; callers cut to this first
    public init?(url: URL)                // nil for anything that isn't the grammar in spec §1
    public var url: URL { get }           // canonical form, uppercase UUID
    public var heading: String? { get }
    public func withHeading(_ heading: String?) -> NoteLink
}

public struct LinkQuery: Equatable, Sendable {   // text typed after "[["
    public var title: String
    public var heading: String?           // after the first "#"
    public var alias: String?             // after the first "|"
    public init(_ raw: String)
}

// Linking/LinkExtractor.swift
struct OutgoingLink: Codable, Equatable, Sendable {
    var url: URL                          // stored as written; NoteLink(url:) on read
    var text: String
    var location: Int                     // UTF-16 offset in the body
    var context: String                   // ≤ 80 characters, one line
    var link: NoteLink? { NoteLink(url: url) }
}
enum LinkExtractor {
    static let maxLinksPerNote = 2_000
    nonisolated static func links(in text: NSAttributedString) -> [OutgoingLink]   // note links only
}

// Linking/OutlineExtractor.swift
struct OutlineItem: Equatable, Sendable { var level: Int; var text: String; var range: NSRange }
enum OutlineExtractor {
    nonisolated static func items(in text: NSAttributedString) -> [OutlineItem]
    nonisolated static func section(of item: OutlineItem, in items: [OutlineItem], length: Int) -> NSRange
}

// Linking/LinkIndex.swift
struct LinkIndexFile: Codable { var version = 1; var entries: [String: Entry]
    struct Entry: Codable { var updatedAt: Date; var links: [OutgoingLink] } }

// Registered with the DerivedIndex registry once per store open and never unregistered (program §7;
// foundations Task 4.4). indexID "links".
// It implements indexID, noteChanged(_:body:), noteRemoved(_:), metadataChanged(_:), rebuild(notes:body:)
// and flush(), with the signatures frozen in foundations; all run on the main actor. noteChanged is never
// called for locked notes, and locking a note calls noteRemoved. metadataChanged keeps entries; deleted
// sources are filtered at query time. flush writes NoteStore.rootURL/link-index.json.
@MainActor final class LinkIndex: ObservableObject, DerivedIndex {
    static let fileName = "link-index.json"
    @Published private(set) var version = 0            // bumps on any change, drives panel refresh
    @Published private(set) var rebuildProgress: (done: Int, total: Int)?
    func set(_ links: [OutgoingLink], for source: UUID)
    func remove(_ source: UUID)
    func outgoing(from source: UUID) -> [OutgoingLink]
    func sources(linkingTo id: UUID, title: String) -> Set<UUID>   // resolved + unresolved by folded title
    func hasEntry(for source: UUID) -> Bool
    func snapshot(updatedAt: [UUID: Date]) -> LinkIndexFile
    func load(_ file: LinkIndexFile, validFor metas: [UUID: Date]) -> Set<UUID>   // returns IDs needing rebuild
}

// Editor/InlineCompletionController.swift (shared; organise adds a TagCompletionSource for "#")
struct InlineCompletionRow: Identifiable, Equatable {
    var id: String; var title: String; var detail: String?; var matched: [Range<String.Index>]; var symbol: String?
}
@MainActor protocol InlineCompletionSource: AnyObject {
    func rows(for query: String) -> [InlineCompletionRow]
    func accept(_ row: InlineCompletionRow, replacing range: NSRange, in textView: NoteItTextView)   // one undo group
    var accessibilityName: String { get }                                                          // "Note link", "Tag"
}
@MainActor final class InlineCompletionController {
    static let maxRows = 8
    init(textView: NoteItTextView)
    var isActive: Bool { get }
    func begin(at location: Int, source: InlineCompletionSource)   // query = text from location to the caret
    func refresh()                                                 // on textDidChange and selection change
    func handle(_ selector: Selector) -> Bool                      // moveUp:, moveDown:, insertNewline:, insertTab:, cancelOperation:
    func end()
}

// Linking/LinkSuggester.swift
struct LinkCandidate: Sendable { var id: UUID; var title: String; var notebookName: String; var updatedAt: Date }
enum LinkSuggestion: Equatable {
    case note(id: UUID, title: String, notebookName: String, matched: [Range<String.Index>])
    case heading(noteID: UUID, text: String, level: Int)
    case create(title: String)
}
enum LinkSuggester {
    static func suggestions(for query: LinkQuery, candidates: [LinkCandidate],
                            headings: (UUID) -> [OutlineItem], limit: Int = 8) -> [LinkSuggestion]
}

// Linking/MentionFinder.swift
enum MentionFinder {
    static let minimumTitleLength = 3
    nonisolated static func ranges(of title: String, in text: NSAttributedString) -> [NSRange]

}

// Linking/NavigationHistory.swift
struct NavigationHistory { static let limit = 50
    mutating func visit(_ id: UUID); mutating func back(isValid: (UUID) -> Bool) -> UUID?
    mutating func forward(isValid: (UUID) -> Bool) -> UUID?; var canGoBack: Bool { get }; var canGoForward: Bool { get } }

// Linking/TemplateExpander.swift
struct TemplateContext { var title: String; var date: Date; var locale: Locale = .current
    var clipboard: () -> String? }        // called at most once, only if {{clipboard}} is present

    static let clipboardLimit = 10_000

// Model/NoteStore+Links.swift
enum LinkResolution: Equatable { case note(UUID, heading: String?), unresolved(title: String), deleted(UUID), missing(UUID) }
struct Backlink: Identifiable { var id: UUID { source }; var source: UUID; var occurrences: [OutgoingLink] }
struct MentionResult: Identifiable { var id: UUID { source }; var source: UUID; var contexts: [String]; var count: Int }
struct LinkRewriteResult { var updated: Int; var skipped: Int; var notes: [UUID: UUID] }   // noteID -> the note's revision right after the change
extension NoteStore {
    var linkIndex: LinkIndex { get }                                    // the instance registered with the DerivedIndex registry
    func resolve(_ link: NoteLink, from source: UUID?) -> LinkResolution
    func followLink(_ link: NoteLink, from source: UUID?)               // editor clicks and automation's .note/.noteTitle handlers
    func noteID(forTitle title: String, preferring notebookID: UUID?) -> UUID?
    func linkCandidates(excluding id: UUID?) -> [LinkCandidate]
    func backlinks(to id: UUID) -> [Backlink]
    func outgoingLinks(from id: UUID) -> [OutgoingLink]
    func unlinkedMentions(of id: UUID) async -> [MentionResult]          // background, cancellable
    func linkMentions(of target: UUID, in sources: [UUID]) async -> (linked: Int, result: LinkRewriteResult)   // via editBody; Link All passes versioning: .recordCurrent, a single Link passes .none
    func renameCandidates(for id: UUID, oldTitle: String) -> [UUID]
    func rewriteLinkText(targeting id: UUID, from oldTitle: String, to newTitle: String) async -> LinkRewriteResult   // editBody(versioning: .recordCurrent) for every changed note
    func undoLinkRewrite(_ result: LinkRewriteResult) -> Int            // restoreVersion of the version editBody recorded; returns notes left alone (edited since)
    func createNoteForLink(title: String, from source: UUID?) -> NoteMeta
    func resolveUnresolvedLink(in source: UUID, at location: Int, to id: UUID)
}

### Milestone 1 — Links, index and panel

### Task 1: Pure link core
**Files:** create `Sources/NoteIt/Linking/LinkExtractor.swift`, `Linking/OutlineExtractor.swift`, `Linking/NavigationHistory.swift`, `Tests/NoteItTests/LinkExtractorTests.swift`, `OutlineExtractorTests.swift`, `NavigationHistoryTests.swift`. `NoteLink` and `LinkQuery` (with `NoteLinkTests`) come from foundations Task 5.3 and aren't created here.

Steps:
- [ ] Check that foundations' `NoteLink` and `LinkQuery` match the frozen shape above and spec §1. A difference is fixed in `Sources/NoteItCore/NoteLink.swift` with a matching case in `NoteLinkTests`, not worked around here.
- [ ] Every place in this plan that builds a link from a title or heading cuts it to `NoteLink.maxTextLength` (120) first, since `NoteLink` rejects longer text.
- [ ] `LinkExtractor.links(in:)`: enumerate `.link` (value may be `URL` or `String`), keep runs where `NoteLink(url:)` succeeds, merge adjacent runs with the same URL, build `context` from the paragraph (newlines and U+2028 to spaces, ≤ 80 characters centred on the link, `…` at cut ends). Stop at `maxLinksPerNote`.
