# Inkwell Web Implementation Plan

**Goal:** Ship a self-hostable Inkwell web app (Nuxt) that is a full end-to-end-encrypted sync peer of the native macOS app. It reads and writes the same `inkwell/v1/` store and ships as one Docker image with a volume for homelabs.

**Architecture:**
- **Phase 0 (native):** introduce a portable note body, `inkwell-doc` (ProseMirror-compatible JSON, versioned), and store format v2 (`formatVersion: 2`, `features`, envelope `bodyFormat`). Add a new SwiftPM target `InkwellDoc` with an NSAttributedString⇄doc converter. Golden vectors are exported from Swift tests into `fixtures/golden/`.
- **Web:** a pnpm workspace in `web/`:
  - `@inkwell/core`: a pure TS port of crypto, formats, planner, engine and storage, verified against the vectors;
  - `@inkwell/doc`: schema, TipTap extensions and derivations;
  - a Nuxt 4 SPA. Its Web Worker runs the sync engine with WebCrypto and IndexedDB.
- **Server:** a Nitro server proxies ciphertext to a disk store or upstream S3. Browsers use `/api/storage`; native apps and rclone use an S3-compatible subset at `/s3`. Auth is password, forward-auth or OIDC.

**Tech Stack:**
- Swift side: Swift 6.3 / SwiftPM / XCTest and AppKit, for the `InkwellDoc` target.
- Web side:
  - Node 24, pnpm 11, TypeScript 5 (strict), Vitest, fast-check;
  - Nuxt 4 (Vue 3, Nitro node-server), Pinia, TipTap 2/ProseMirror;
  - `idb`, Comlink, DOMPurify, nuxt-security, @vite-pwa/nuxt, `@node-rs/argon2`, `openid-client`;
  - Playwright.
- Deployment: Docker (node:24-alpine) and docker-compose. Floci S3 is used for interop tests.

**Spec:** `docs/specs/2026-10-13-web-app-design.md`. Section numbers like "§2.3" below refer to it. The spec's §2 is the byte-level format contract.

## Conventions for every task

- Swift tests: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --filter <Suite> 2>&1 | tail -20`. App build: `swift build 2>&1 | tail -3` must end with `Build complete!`.
- Web tests (from repo root):
  - unit: `pnpm -C web -r test`;
  - single package: `pnpm -C web --filter @inkwell/core test`;
  - typecheck: `pnpm -C web -r typecheck`;
  - lint: `pnpm -C web lint`;
  - E2E: `pnpm -C web e2e`.
- **Test first.** Every task begins by adding failing tests or vectors. Commit only once they pass.
- Never touch `~/Library/Application Support/Inkwell`. Native runs use `INKWELL_DATA_DIR=<repo>/.selftest/<name>`.
- Commits follow Conventional Commits, one or more per task (e.g. `feat(web-core): add AES-GCM cipher`). Never amend, rebase or force-push.
- **UUIDs are uppercase** everywhere they are written (keys and JSON). Inner-meta dates are `YYYY-MM-DDTHH:MM:SSZ`. Envelope, tombstone, device and manifest dates are Double2001 numbers (spec §2.2).
- No third-party runtime scripts, fonts or CDNs. TS must compile in `strict` mode with `noUncheckedIndexedAccess`.
- Comments only where something is non-obvious.
