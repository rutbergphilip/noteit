# NoteIt Plugins Implementation Plan

**Goal:** Ship a plugin system: JavaScript plugins run in a sandboxed JavaScriptCore helper process, declare a
manifest with permissions, add commands to the palette and the Plugins menu, transform the open note, show
notices, prompts and native panels, and are installed from a `.noteitplugin` file or a signed community
directory on GitHub. Three bundled example plugins are the acceptance tests.

**Architecture:**
- A new library target, `NoteItPlugins` (macOS, depends on `NoteItCore` only, per the program's target
  graph), holds everything testable without AppKit. Platforms are package-wide, so it also compiles on iOS;
  macOS-only code in it sits under `#if os(macOS)`, and only the Mac app links it:
  - manifest model and validation, semantic versions, permissions;
  - the JSON value type, the API error type and the app/host frame protocol;
  - package entry validation, UI tree validation, network policy, the watchdog state machine;
  - the directory index model and its Ed25519 verification;
  - `PluginRuntime`, which wraps one `JSContext` and installs the `noteit` global, forwarding every call to a
    `PluginRuntimeBridge`.
- A new executable target, `NoteItPluginHost` (depends on `NoteItPlugins`), is a thin loop: read frames from
  stdin, drive one `PluginRuntime`, write frames to stdout. It is one row in the embeds table in `scripts/build_app.sh`
  (foundations task 5.5): copied to `Contents/Helpers/NoteItPluginHost`, its `Info.plist` embedded by the script, signed
  inside-out with app-sandbox only (and the hardened runtime in distribution builds), with no JIT entitlement.
- The app target gets `Sources/NoteIt/Plugins/`:
  - `PluginManager` (state, lifecycle, palette and menu contributions);
  - `PluginProcess` (spawn, frames, watchdog, kill);
  - `PluginAPIHandler` (permission checks, then `NoteStore`, editor, UI, clipboard, network). Every note
    write goes through `NoteStore.editBody`; Markdown goes through `NoteItMarkdown` in the `library` flavour;
  - installer, directory client, panel renderer, sheets;
  - plus a Settings › Plugins tab.
- `plugins-sdk/` is a standalone pnpm package with the TypeScript declarations, manifest schema, the
  `noteit-plugin` CLI and the directory CI scripts.
- Plugins are wave 3. Wave 0 (`NoteItCore`, `NoteMeta.isLocked`, `NoteStore.editBody`, `OpenEditorRegistry` and
  the `localNoteChange` notification (4.5), `LocalAPIRouteRegistry` (5.2), the embeds table (5.5), the Settings
  tab table (6.3)), wave 1 (`automation`, `markdown-storage`, `linking`, `organise`) and wave 2's
  `web-clipper` T4 (`PinnedHTTPClient` in `Sources/NoteIt/Net/`) have landed before T1, so no task writes stubs
  for them.

**Tech stack:** Swift 6.3 toolchain in Swift 5 language mode, SwiftPM, JavaScriptCore, CryptoKit
(SHA-256, Curve25519), Foundation (`Process`; `URLSession` only for the directory fetch), `web-clipper`'s
`PinnedHTTPClient` for every plugin request, SwiftUI/AppKit. No new Swift dependencies.
`/usr/bin/zipinfo` and `/usr/bin/ditto` for archives. SDK: Node 24, pnpm 11, TypeScript 5 (strict), esbuild,
Ajv, Vitest. Tests use XCTest via `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`.

**Spec:** `docs/specs/2026-10-19-plugins-design.md`. Section numbers like "§4.3" refer to it.

## Conventions for every task

- Swift tests (repository root):
  `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --filter <Suite> 2>&1 | tail -20`,
  expected to end with `Executed N tests, with 0 failures`.
- App build: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build 2>&1 | tail -3` and `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build -c release 2>&1 | tail -3` both end with
  `Build complete!` and no errors.
- SDK: `cd plugins-sdk && pnpm install --frozen-lockfile && pnpm test && pnpm typecheck`.
- Never touch real user data in `~/Library/Application Support/NoteIt`. When running the app, set
  `NOTEIT_DATA_DIR="$PWD/.selftest/<name>"`, run from the repository root (already gitignored). Plugin data then lives in
  `.selftest/<name>/plugins/`.
- Tests that need the host executable find it next to the test bundle
  (`Bundle(for: Self.self).bundleURL.deletingLastPathComponent().appendingPathComponent("NoteItPluginHost")`)
  or at `NOTEIT_PLUGIN_HOST` when set. `NoteItPluginsTests` depends on `NoteItPluginHost` so it is built.
- Commit after each task with Conventional Commits, scope `plugins`, e.g. `feat(plugins): add manifest
  validation`. Never amend, rebase or force.
- No `#Preview`. Comments only where something is non-obvious.
- Everything in `NoteItPlugins` the app or host needs is `public` and `Sendable`-correct. `NoteItPlugins`
  imports Foundation, CryptoKit, JavaScriptCore and `NoteItCore` only, never AppKit. It must build for iOS;
  anything macOS-only (for example `Process` or `proc_pid_rusage`) stays in the app or the host, or sits under
  `#if os(macOS)`.
- Main-actor rules from `AppDelegate`: notification callbacks hop with `Task { @MainActor in … }`; nothing
  touches `UserDefaults` inside a defaults-change callback.
- Frame handling never blocks the main thread: `PluginProcess` reads on a background queue and delivers
  decoded messages on the main actor.

public enum JSONValue: Codable, Sendable, Equatable, Hashable {
    case null, bool(Bool), number(Double), string(String), array([JSONValue]), object([String: JSONValue])
}
public struct SemanticVersion: Comparable, Codable, Sendable, Hashable, LosslessStringConvertible {
    public let major: Int, minor: Int, patch: Int; public let prerelease: String?
    public static let development: SemanticVersion          // 0.0.0-dev, compares greater than everything
}
public enum PluginPermission: Hashable, Sendable, Codable, Comparable {
    case notesRead, notesWrite, editor, clipboard, uiPanel, network(host: String)
    public init?(rawValue: String); public var rawValue: String
    public func allows(host: String) -> Bool                 // exact or one-label wildcard
}
public struct PluginManifest: Codable, Sendable, Equatable {
    public struct Author: Codable, Sendable, Equatable { public var name: String; public var url: URL? }
    public enum When: String, Codable, Sendable { case always, note, selection }
    public struct Command: Codable, Sendable, Equatable { public var id, title: String; public var symbol: String?; public var keywords: [String]; public var when: When }
    public struct Panel: Codable, Sendable, Equatable { public var id, title: String; public var symbol: String? }

        public struct Option: Codable, Sendable, Equatable { public var value, title: String }
    }
    public var manifestVersion: Int; public var id, name: String
    public var version, minAppVersion: SemanticVersion
    public var description, license: String?; public var author: Author?; public var homepage: URL?
    public var main: String; public var icon: String?
    public var permissions: [PluginPermission]
    public var commands: [Command]; public var panels: [Panel]; public var events: [PluginEvent]; public var settings: [Setting]

public enum AppToHost: Codable, Sendable, Equatable {
    case load(LoadPayload)                                   // first frame
    case invokeCommand(callID: Int, commandID: String, context: JSONValue)
    case panelAction(callID: Int, panelID: String, elementID: String, value: JSONValue?)
    case panelShown(panelID: String)
    case event(callID: Int, name: PluginEvent, payload: JSONValue)
    case settingChanged(key: String)
    case reply(apiCallID: Int, result: Result<JSONValue, PluginAPIError>)
    case ping(seq: Int)
    case shutdown
}
public struct LoadPayload: Codable, Sendable, Equatable {
    public var manifest: PluginManifest; public var source: String; public var granted: [PluginPermission]

}
public enum HostToApp: Codable, Sendable, Equatable {
    case ready(registered: [String])
    case api(apiCallID: Int, method: PluginAPIMethod, params: JSONValue)
    case done(callID: Int, error: PluginAPIError?)
    case log(level: PluginLogLevel, message: String)
    case pong(seq: Int)
    case fatal(message: String)
}
public enum PluginLogLevel: String, Codable, Sendable { case debug, info, warn, error }
public enum PluginAPIMethod: String, Codable, Sendable, CaseIterable {
    case notesCurrent, notesGet, notesSearch, notesList, notesCreate, notesUpdate, notesAppend, notebooksList
    case editorText, editorSelection, editorLines, editorReplaceSelection, editorInsert, editorReplaceLines
    case uiToast, uiPrompt, uiConfirm, panelRender
    case clipboardRead, clipboardWrite, netFetch
    case storageGet, storageSet, storageRemove, settingsGet
    public var requiredPermission: PluginPermission? { get }   // netFetch is checked per host by NetworkPolicy
    public var needsInteractionWindow: Bool { get }           // editor writes, uiPrompt, uiConfirm
}
public enum FrameCodec {
    public static let maxFrameBytes = 8 << 20
    public static func encode<T: Encodable>(_ value: T) throws -> Data           // 4-byte big-endian length + JSON

}

    public enum Verdict: Equatable, Sendable { case ok, sendPing(seq: Int), timeOut(callID: Int), kill(reason: KillReason) }
    public enum KillReason: String, Sendable { case startup, unresponsive, callTimeout, memory }
    public init(limits: PluginLimits)
    public mutating func processStarted(at: Date)
    public mutating func ready(at: Date)
    public mutating func callStarted(_ id: Int, kind: CallKind, at: Date)    // .command | .panelAction | .event
    public mutating func callEnded(_ id: Int)

public struct DirectoryIndex: Codable, Sendable, Equatable {
    public struct Entry: Codable, Sendable, Equatable { public var id, name: String; public var versions: [Version] /* + spec fields */ }
    public struct Version: Codable, Sendable, Equatable { public var version, minAppVersion: SemanticVersion

    public struct Revocation: Codable, Sendable, Equatable { public var id: String; public var versions: [SemanticVersion]; public var reason: String }
    public var schemaVersion: Int; public var plugins: [Entry]; public var revoked: [Revocation]
    public func bestVersion(of id: String, appVersion: SemanticVersion) -> Version?
    public func revocation(id: String, version: SemanticVersion) -> Revocation?
    public static func isAllowedDownload(_ url: URL) -> Bool        // https://github.com/<o>/<r>/releases/download/…
}
public enum DirectoryVerifier {
    public static func verify(index: Data, signature: Data, publicKeys: [Data]) throws -> DirectoryIndex
}

    public func panelShown(_ panelID: String)

    public func settingChanged(_ key: String)
}

@MainActor final class PluginWriteBatch {                   // one per command run, panel action or event handler
    struct Entry { var revisionBefore: UUID; var bodyBefore: NSAttributedString; var revisionAfter: UUID }

// Consumed from web-clipper (its T4, Sources/NoteIt/Net/PinnedHTTPClient.swift), not redeclared here:
// PinnedHTTPClient, PinnedHTTPPolicy, PinnedHTTPRequest, PinnedHTTPResponse, PinnedHTTPError, HostResolving, PinnedTransporting.
protocol PluginNetworkFetching: Sendable {
    func fetch(_ request: PinnedHTTPRequest, pluginID: String, granted: [PluginPermission]) async -> Result<PinnedHTTPResponse, PluginAPIError>
}
actor PluginNetworkGate: PluginNetworkFetching {
    init(client: PinnedHTTPClient = PinnedHTTPClient(), now: @escaping @Sendable () -> Date = Date.init)
    /// NetworkPolicy.check first, then client.send with policy(for:); PinnedHTTPError → PluginAPIError:
    /// notAllowed → NetworkBlocked, tooLarge → TooLarge, timedOut and network → NetworkFailed.
    func fetch(_ request: PinnedHTTPRequest, pluginID: String, granted: [PluginPermission]) async -> Result<PinnedHTTPResponse, PluginAPIError>
    /// allowsURL = NetworkPolicy.allowsRedirect(to:granted:); allowsLoopback = host is "localhost" or "127.0.0.1" and
    /// granted by that exact name; methods GET POST PUT PATCH DELETE HEAD; 1 MB body; 5 MB response; 15 s; 5 redirects.
    static func policy(for granted: [PluginPermission]) -> PinnedHTTPPolicy
}
