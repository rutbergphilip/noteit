# Inkwell Sync Implementation Plan

**Goal:** Let the user sync their Inkwell library across Macs through storage they own: a folder (NAS mount, iCloud Drive, Dropbox) or any S3-compatible bucket. Encryption is end-to-end and on by default, conflicts are never lost, and the performance budget is strict.

**Architecture:** A new library target, `InkwellSync`, contains everything that can be tested without the UI:
- storage backends (Folder, S3 with SigV4, InMemory);
- AES-GCM encryption with PBKDF2 key derivation;
- a pure decision function that picks a sync action per record;
- an actor `SyncEngine` that talks to the app only through the `SyncLocalStore` protocol.

The app target adds revision tracking to `NoteStore`, an adapter, a `SyncController` (scheduling, status, keychain), a Sync settings tab and status UI.

**Tech Stack:** Swift 6.3 toolchain in Swift 5 language mode, SwiftPM, Foundation/URLSession, CryptoKit, CommonCrypto, Security (keychain), SwiftUI/AppKit. No third-party dependencies. Tests use XCTest via `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`, because the CLT-only toolchain has no XCTest. App builds keep using plain `swift build`.

**Spec:** `docs/specs/2026-10-12-sync-design.md`

**Deliberate deviation from the spec:** the local on-disk layout (`library.json` + `notes/<id>.rtfd`) is NOT migrated.
- Locally there is a single writer, so splitting into per-record files is only needed remotely.
- Phase 1 is reduced to two things: an optional `revision` field on `NoteMeta`/`Notebook` (decoded as nil from existing files, filled in lazily), and a local sync deletion journal.
- This means zero migration risk for existing user data.

## Frozen interfaces (InkwellSync)

```swift
// Storage/StorageBackend.swift
public struct RemoteObject: Sendable, Hashable, Codable { public let key: String; public let etag: String; public let size: Int }
public enum StorageError: Error, Sendable, Equatable {
    case notFound(String), preconditionFailed(String), unauthorized(String), network(String), invalidResponse(String), io(String)
}
public protocol StorageBackend: Sendable {
    func list(prefix: String) async throws -> [RemoteObject]          // handles pagination internally
    func get(_ key: String) async throws -> (data: Data, etag: String)
    /// ifMatch: write only if current etag equals it. ifNoneMatch: write only if key absent. Returns new etag.
    @discardableResult func put(_ key: String, data: Data, ifMatch: String?, ifNoneMatch: Bool) async throws -> String
    func delete(_ key: String) async throws
    func probe() async throws                                          // reachability/auth check for "Test connection"
}

// Crypto
public protocol SyncCipher: Sendable { func seal(_ plain: Data) throws -> Data; func open(_ sealed: Data) throws -> Data }
public struct PassthroughCipher: SyncCipher { public init() }
public struct AESGCMCipher: SyncCipher { public init(key: SymmetricKey) }   // combined nonce|ciphertext|tag
public enum KeyDerivation {
    public static func deriveKey(passphrase: String, salt: Data, iterations: Int) -> SymmetricKey   // PBKDF2-HMAC-SHA256, 32 bytes
    public static func randomSalt() -> Data                                                           // 16 bytes
}

// Model/SyncTypes.swift
public enum RecordKind: String, Codable, Sendable { case notebook, note }
public struct LocalRecord: Sendable, Hashable { public var id: UUID; public var kind: RecordKind; public var revision: UUID; public var modifiedAt: Date }
public struct RecordPayload: Sendable {
    public var id: UUID; public var kind: RecordKind; public var revision: UUID; public var modifiedAt: Date
    public var deviceID: String; public var meta: Data; public var body: Data?
}
public struct RemoteEnvelope: Codable, Sendable {      // stored sealed at the meta key
    public var id: UUID; public var kind: RecordKind; public var revision: UUID; public var modifiedAt: Date
    public var deviceID: String; public var deviceName: String; public var meta: Data; public var bodySHA256: String?
}
public struct Tombstone: Codable, Sendable, Hashable { public var id: UUID; public var kind: RecordKind; public var deletedAt: Date; public var deviceID: String }
public struct DeviceInfo: Codable, Sendable, Hashable { public var deviceID: String; public var name: String; public var lastSync: Date }

// Model/Manifest.swift
public struct Manifest: Codable, Sendable, Equatable {
    public var formatVersion: Int                       // 1
    public var encryption: Encryption?                  // nil = plaintext
    public struct Encryption: Codable, Sendable, Equatable { public var salt: Data; public var iterations: Int; public var keyCheck: Data } // keyCheck = seal("inkwell-key-check")
    public var createdAt: Date
}

// Engine/RemoteLayout.swift — root "inkwell/v1/"
public enum RemoteLayout {
    public static let root = "inkwell/v1/"
    public static func manifest() -> String                          // inkwell/v1/manifest.json (never encrypted)
    public static func meta(_ kind: RecordKind, _ id: UUID) -> String // inkwell/v1/notebooks/<id>.json | inkwell/v1/notes/<id>.meta
    public static func body(_ id: UUID) -> String                    // inkwell/v1/notes/<id>.body
    public static func tombstone(_ id: UUID) -> String               // inkwell/v1/tombstones/<id>.json (sealed)
    public static func device(_ deviceID: String) -> String          // inkwell/v1/devices/<deviceID>.json (sealed)
}

// Model/SyncState.swift
public struct SyncState: Codable, Sendable, Equatable {
    public struct Base: Codable, Sendable, Equatable { public var revision: UUID; public var remoteMetaETag: String }
    public var bases: [UUID: Base] = [:]
    public var knownTombstones: Set<UUID> = []
    public var lastDeviceWrite: Date?
    public static func load(from url: URL) -> SyncState      // missing/corrupt -> empty
    public func save(to url: URL) throws                     // atomic
}

// Engine/SyncPlanner.swift
public struct RemoteInfo: Sendable, Equatable { public var metaETag: String?; public var tombstone: Tombstone? }   // metaETag nil = no remote meta
public enum SyncAction: Equatable, Sendable { case none, push, pull, pushDeletion, applyRemoteDeletion, conflict, resurrectPush, forgetBase }
public enum SyncPlanner {
    public static func decide(local: LocalRecord?, localDeletedAt: Date?, remote: RemoteInfo, base: SyncState.Base?) -> SyncAction
}

// Engine/SyncEngine.swift
public protocol SyncLocalStore: Sendable {
    func records() async -> [LocalRecord]
    func deletions() async -> [UUID: LocalDeletion]
    func export(_ id: UUID, kind: RecordKind) async throws -> RecordPayload
    func apply(_ payload: RecordPayload) async throws                          // insert/replace keeping payload.revision
    func applyDeletion(_ id: UUID, kind: RecordKind) async throws
    func importConflictCopy(_ payload: RecordPayload, fromDevice name: String) async throws  // new id + new revision
    func clearDeletion(_ id: UUID) async
}
public struct LocalDeletion: Sendable, Equatable { public var kind: RecordKind; public var deletedAt: Date }
public struct SyncReport: Sendable, Equatable { public var pushed = 0, pulled = 0, deleted = 0, conflicts = 0, skipped = 0; public var errors: [String] = [] }
public enum SyncError: Error, Equatable, Sendable { case wrongPassphrase, passphraseRequired, unsupportedFormat(Int), encryptionMismatch }
public actor SyncEngine {
    public init(backend: StorageBackend, cipher: SyncCipher, local: SyncLocalStore, stateURL: URL, deviceID: String, deviceName: String)
    public func sync() async throws -> SyncReport     // throws only fatal errors (unauthorized, manifest problems)
    public func devices() async throws -> [DeviceInfo]
    public static func connect(backend: StorageBackend, passphrase: String?, encryptNew: Bool) async throws -> (Manifest, SyncCipher)
}
```

### SyncPlanner decision table (cover 1:1 with tests)

Legend:
- L: the local record exists.
- Ld: a local deletion is journaled.
- R: `remote.metaETag != nil`.
- Rt: `remote.tombstone != nil`.
- B: a base exists.
- ΔL: `local.revision != base.revision`.
- ΔR: `remote.metaETag != base.remoteMetaETag`.

Evaluate the rows top to bottom; the first match wins.

| # | Condition | Action |
|---|---|---|
| 1 | L, no B, no R, no Rt | push |
| 2 | no L, no Ld, R, no B | pull |
| 3 | L, R, B, !ΔL, !ΔR | none |
| 4 | L, R, B, ΔL, !ΔR | push |
| 5 | L, R, B, !ΔL, ΔR | pull |
| 6 | L, R, B, ΔL, ΔR | conflict |
| 7 | L, R, no B | conflict (independent creation with the same id, e.g. after a restore) |
| 8 | Ld, R, B, !ΔR | pushDeletion |
| 9 | Ld, R, B, ΔR | pull (a remote edit after our base beats the local delete, so nothing is lost; the engine then clears the deletion) |
| 10 | Ld, no R, no Rt | pushDeletion |
| 11 | L, Rt, (B or no B), !ΔL (or no B) | applyRemoteDeletion |
| 12 | L, Rt, B, ΔL | resurrectPush if local.modifiedAt > tombstone.deletedAt else applyRemoteDeletion |
| 13 | L, no R, no Rt, B | push if ΔL else applyRemoteDeletion |
| 14 | no L, no Ld, Rt | forgetBase |
| 15 | Ld, Rt | forgetBase (both deleted; the engine also clears the deletion) |
| 16 | no L, no Ld, no R, no Rt, B | forgetBase |
| 17 | Ld, R, no B | pull (we never synced it; the remote is someone else's live note) |

For notebooks, the engine resolves `.conflict` as last-writer-wins by comparing `local.modifiedAt` with the envelope's `modifiedAt`.

### SyncEngine pass

1. Run one `list(RemoteLayout.root)`. It returns all metas, bodies, tombstones and devices with their ETags. Tombstones are tiny, and a tombstone is fetched only when it is relevant: its id has a local record or a deletion, and it isn't in `knownTombstones` with a matching ETag.
2. Load `SyncState`, then get `records()` and `deletions()` from the local store.
3. For each id in the union, `decide`, then run the actions one after another, with at most one body in memory at a time.
   - **push:**
     1. `export` the record.
     2. If it has a body, `put` the sealed body first.
     3. `put` the meta (sealed envelope with `bodySHA256`), using `ifMatch: base?.remoteMetaETag` if there is a base, else `ifNoneMatch: true`. On `preconditionFailed`, mark it skipped; the next pass re-decides.
     4. Update the base, and delete any remote tombstone for that id.
   - **pull:**
     1. `get` the meta, `open` it and decode the envelope.
     2. If there is a body, `get` and `open` it, then verify its SHA-256. On a mismatch, skip (the upload is still in progress).
     3. `apply`, then update the base.
   - **conflict (notes):** pull the remote payload and call `importConflictCopy`. Then push local over remote with `ifMatch` set to the current remote ETag. **(notebooks):** last writer wins.
   - **pushDeletion:** `put` the tombstone, `delete` the meta and body (ignore `notFound`), `clearDeletion`, then remove the base.
   - **applyRemoteDeletion:** `applyDeletion`, then remove the base.
   - **resurrectPush:** push, then delete the tombstone.
   - **forgetBase:** remove the base, and `clearDeletion` if there is one.
4. `put` the device record at most once per 10 minutes.
5. Save `SyncState` atomically after every action that changes it, so a crash resumes cleanly.
6. Sweep tombstones older than 30 days: delete them remotely and remember them in `knownTombstones`.
7. Per-record errors such as network or decode failures go into `report.errors` and the pass continues. `unauthorized` aborts the pass by throwing.

    - It replaces or inserts the meta while keeping the payload's revision.
    - It writes the body through the existing safe write path without bumping the revision, and refreshes the cache, search index, title, preview and tags.
    - It sets `@Published var externallyUpdatedNoteID: UUID?`.
    - If the notebook referenced by a pulled note doesn't exist yet, the note is kept: its notebookID is kept as-is and the note shows under All Notes until the notebook arrives.
  - `applyRemoteDeletion(_:kind:)` reuses the delete path minus the journal. A deleted notebook moves its notes to no notebook, without bumping their revisions.
  - `importConflictCopy(_:fromDevice:)` creates a new UUID, adds the title suffix ` (conflict — <device>, <short date>)`, sets `conflictSource`, and gives a fresh revision.
  - `clearSyncDeletion(_:)`.
